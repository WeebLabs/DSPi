# DSPi front-panel UI: XIAO RP2350 + ST7735 1.8" TFT, OP-1 style

Running on hardware: XIAO RP2350, PCM5102 over I2S, a 1.8" ST7735 160x128 TFT ("green tab" module) and one
button on D6. The host tests in `test/` predate the TFT port (their `out*/` images show the old 96x64 layout).

## Wiring

| Signal | XIAO pin | GPIO | Goes to |
|---|---|---|---|
| I2S BCK | D0 | 26 | PCM5102 BCK |
| I2S LRCK | D1 | 27 | PCM5102 LCK (always BCK + 1) |
| I2S DATA | D2 | 28 | PCM5102 DIN |
| Display RES | D3 | 5 | TFT RES |
| Display CS | D7 | 1 | TFT CS |
| Display SCK | D8 | 2 | TFT SCL/SCK |
| Display DC | D9 | 4 | TFT DC (A0/RS) |
| Display MOSI | D10 | 3 | TFT SDA |
| Button | D6 | 0 | push button to GND (internal pull-up) |
| do not use | D4, D5 | 6, 7 | idle S/PDIF slot pins DSPi drives at boot |

PCM5102: SCK pin tied to GND (internal PLL, no MCLK needed). Display and DAC on 3V3. The TFT's BL pin is left
unconnected (the module keeps its backlight on), so brightness is done by dimming the picture.

## Display

`st7735.c` drives the panel in landscape over SPI0 at up to 26 MHz, flushing the 40 KB RGB565 framebuffer with
DMA channel 9; frames are drawn in 8 bands from a background job (`ui.c`, `ui_pages.c`). Panel options live in
`ui_board.h`:

* `UI_DISP_MADCTL` (0xA0): orientation and colour order. Add 0x08 for BGR modules (orange showing as blue means
  this is wrong); 0x60 rotates 180 degrees.
* `UI_DISP_X_OFS` / `UI_DISP_Y_OFS` (1, 2): the RAM offset of green-tab modules. Noise along the bottom and right
  edges means it is wrong; 0, 0 for red/black-tab modules.
* `UI_DISP_SPI_HZ`: lower it (13 MHz) for long wiring.

Brightness levels (SYS page, idle dim) scale the colours; sleep after 2 minutes shows a black frame, since an
ST7735 switched off shows white.

## Fonts

Text uses the "geometric rounded" font (Gugi-inspired: round pen, quarter-circle corners, square corners on
stems) at 2x/3x/4x and the squared "Block" capitals at 1x, both generated by `tools/ui_fontgen.py` into
`font_round.h` and `font_block.h`. Text draws in capitals; `gfx_text_center_cased()` keeps the one lowercase
glyph (the "d" of dB). In `gfx.c`, `UI_FONT_ROUND 0` keeps the Block capitals at every size and
`UI_FONT_BLOCK 0` returns to the classic 5x7 font. To change a glyph or the stroke weight, edit
`tools/ui_fontgen.py` and run `python tools/ui_fontgen.py` from the repo root.

## Controls (one button)

* Top level: short press = next page (NOW, EQ, FX, PRESETS, SYS); long press (0.6 s) = open that page's menu.
  On NOW a long press toggles mute.
* In a menu: short press = next item; long press = activate it. The last item is always "back".
* Display dims after 30 s and blanks after 2 min without USB streaming; any press wakes it (that press does
  nothing else).
* RGB LED: green = streaming, slow blue blink = idle, orange = muted, red = clip, page colour while a menu is
  open, white while holding toward a long press. The LED and display levels are changed on the SYS page and are
  not saved.

## NOW page

Volume dial with the level in dB, L/R output meters (green, two orange segments, then a dim red near-clip zone
that lights bright red when reached), sample rate and USB-streaming dot in the header, and the input source
(its user name when set) in the footer, white while it has signal.

## Build

`-DPICO_BOARD=seeed_xiao_rp2350` turns the UI on automatically (`-DDSPI_UI=ON/OFF` overrides). With the
Raspberry Pi Pico VS Code extension's tools on Windows (no host compiler), point CMake at its prebuilt helpers:

```
cmake -S firmware -B build-xiao-ui -G Ninja -DPICO_PLATFORM=rp2350-arm-s -DPICO_BOARD=seeed_xiao_rp2350 \
  -Dpioasm_DIR=%USERPROFILE%/.pico-sdk/tools/2.2.0/pioasm \
  -Dpicotool_DIR=%USERPROFILE%/.pico-sdk/picotool/2.2.0-a4/picotool
cmake --build build-xiao-ui -j
```

`scripts/check_ram_placement.py` passes with the 40 KB framebuffer (it picks the platform from the path, so the
ELF's path must contain "rp2350").

## Notes

1. DSPi's default S/PDIF RX pin (GPIO 5) and I2S RX pin (GPIO 1) collide with display RES/CS. On the bench unit
   they were moved to GPIO 11 and 12 and saved in preset 0; a preset created from defaults brings the collision
   back.
2. A previously saved output config overrides the factory defaults (I2S on 26/27/28).
3. The "saved pN" toast appears when the save is requested; it does not wait for the flash write result.
4. The BOOT-button read path (`UI_BTN_SOURCE = UI_BTN_SRC_BOOTSEL`) briefly tri-states the flash chip-select;
   the default is the external button on D6.
